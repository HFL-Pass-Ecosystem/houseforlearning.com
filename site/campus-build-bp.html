campus build · BP · business park tier

Business-park campus

Twenty-four modules on two floors, or the same spaces fitted into a rented floor of about 340 m2. Two studios below, project and quiet spaces above.

Try the campus builderLOD stage plan

at a glance

Size and capacity

  • Tier: Business park
  • Modules: 24
  • Floors: 2
  • Floor area: about 336 m2
  • Learners at one time: 84
  • Rooms: 15

Used for. A campus close to employers: core learning, project rooms and a coffee bar. Specialist labs are booked at the flagship.

build order

How it is put together

  1. Agree the base, the crane position and the lift order with the engineer.
  2. Place the twelve ground modules, then the stairs, then the twelve upper modules and the two terraces.
  3. Seal the roof, fit the glass walls, doors, rails and the platform lift.
  4. Run services floor by floor: power, cooling, water, drainage, data, fire. Test each before finishes close it in.
  5. Finishes, furniture and signs. Walk every exit route, then hand over with the as-built model.

model files

File names for this build

  • C01-B1-L1-ARC: architecture model, floor 1
  • C01-B1-L1-STR: structure model, floor 1
  • C01-B1-L1-MEP: services model, floor 1
  • C01-B1-L2-ARC: architecture model, floor 2
  • Replace C01 with the number of the real campus. The element code follows when a file holds one element type, for example C01-B1-L1-ARC-CS-SH-05 for the glass wall.

practice files

Download and open the model

A practice model of this campus type in an open format (IFC), at LOD 200. It holds 24 module shells on 2 floors. Each shell carries its element code, its level of development and the space it belongs to. Doors, walls and furniture are left for you to add.

  • Practice model, Business-park campus (IFC file)
  • Element list, Business-park campus (CSV file, opens in any spreadsheet)
  • Open the model in any free viewer that reads open IFC files. Click one module and read its properties: you will see the code CS-SH-01 and LOD 200.
