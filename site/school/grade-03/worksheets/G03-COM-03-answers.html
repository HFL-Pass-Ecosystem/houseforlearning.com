Algorithms and loops without a computer

Computing and Digital Skills · Grade 3 · TEACHER ANSWER KEY

Answers are shown in green. Accept any correct answer in the learner's own words. Marking: 1 mark for each question unless stated.
1.What is an algorithm?
Answer: A set of steps in order to do a task.
2.Put the steps in order: put on socks, wake up, put on shoes.
Answer: Wake up, put on socks, put on shoes.
3.What does "repeat 3 times" tell us to do?
Answer: Do the steps three times.
4.Rewrite with a loop: step, step, step, step.
Answer: Repeat 4 times: step.
5.What is a bug in an algorithm?
Answer: A mistake.
6.Find the bug: Draw a square: forward, turn, forward, turn, forward.
Answer: One side and turn are missing; it needs four sides.
7.Write four steps for drawing a triangle with arrows.
Answer: Any correct steps ending in a closed triangle.
8.Why must instructions be exact?
Answer: So the machine or partner does what we intend.
9.Draw an arrow path on a grid from A to B.
Answer: Any valid path.
10.Write an algorithm for making tea using a loop for stirring.
Answer: Observe: sequence, a loop (stir 5 times) and a clear end.
