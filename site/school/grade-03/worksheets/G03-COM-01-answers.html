Pictures and shapes in a drawing program

Computing and Digital Skills · Grade 3 · TEACHER ANSWER KEY

Answers are shown in green. Accept any correct answer in the learner's own words. Marking: 1 mark for each question unless stated.
1.What does the "undo" button do?
Answer: It takes back the last thing you did.
2.How do you save a picture?
Answer: Choose Save, type a name and pick a folder.
3.Which tool fills a closed shape with colour?
Answer: The fill tool.
4.What does "rotate" do to a picture?
Answer: Turns it around.
5.What does "flip" do?
Answer: Makes a mirror picture.
6.Name two shape tools.
Answer: Any two, for example rectangle, circle.
7.How can we make a picture bigger without losing its shape?
Answer: Resize while keeping the sides in proportion.
8.Why do we give a file a clear name?
Answer: So we can find it later.
9.Draw and save a picture of a house with three shapes.
Answer: Observe: shapes, colours, saved file with a name.
10.Write one tip you would give a friend about the drawing program.
Answer: Any useful tip.
