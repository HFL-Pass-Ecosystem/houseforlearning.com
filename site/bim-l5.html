BIM academy · L5 Specialist · 24 hours

Fabrication models, programme and cost (LOD 350 to 400)

Prepare factory-ready modules, link the model to a build programme and to cost, and plan site assembly.

BIM academyThe BIM and LOD rules

task, condition, standard

What you will be able to do

  • Task. Prepare a fabrication model of one module with stair and glass wall, and link it to a build programme and cost list.
  • Condition. A coordinated LOD 350 model, our module rules and a short build programme template.
  • Standard. Fabrication drawings list every part, programme shows assembly order, and cost list traces to model elements.

four modules

Modules, with worked examples

Module 1: Detailing for the factory (6 h; Create)
  • Each part gets a mark, a size and a fixing.
  • Tolerances are stated so parts fit on site.
  • Check transport size: a module must fit a standard truck and crane.

Worked example. A stair is split into flights that can be lifted by two people, each with marks.

Activity. Create the fabrication detail for one stair.

Standard. Every part marked and sized.

Module 2: Link the model to time (4D) (6 h; Analyse)
  • Order the work: base, frame, panels, services, finishes.
  • Link each element to a task and a duration.
  • Look for waiting time and crowded days.

Worked example. Placing a terrace before the stair is ready blocks access. The 4D view shows it.

Activity. Link ten elements to tasks.

Standard. Order shows no blocked access.

Module 3: Link the model to cost (5D) (6 h; Evaluate)
  • Cost lines point to element codes.
  • Update the cost when the model changes.
  • Keep price data in a private area, never in public files.

Worked example. Changing a sliding door to a single door changes the cost list automatically.

Activity. Build a cost list for one module.

Standard. Every line traces to an element code.

Module 4: Plan site assembly and safety (6 h; Evaluate)
  • Plan crane positions, lift sizes and exclusion zones.
  • Plan how a worker reaches the work at height.
  • Record risks and the control for each.

Worked example. A crane radius of 12 m covers the terrace lift but not the far stair. Add a second pick.

Activity. Write a lift plan for the stack.

Standard. Each lift has a control stated.

five checks

Check yourself

Think of your answer first, then open the question.

Q1. Why state tolerances?

Model answer. So parts made apart fit together on site.

Q2. What does 4D add to a model?

Model answer. Time: the build order and duration linked to elements.

Q3. What does 5D add?

Model answer. Cost linked to element codes.

Q4. Why keep price data private?

Model answer. Prices are commercial information and must not appear in public files.

Q5. Name one thing a lift plan must state.

Model answer. Crane position, lift size or the exclusion zone.

where this takes you

Jobs this supports

  • Fabrication modeller. Prepares factory-ready models.
  • 4D and 5D planner. Links models to time and cost.
