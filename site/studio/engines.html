Engines

Two working engines. The ingest engine reads many kinds of file into one table. The collate engine pulls data from several web addresses (APIs) and joins it into one table. Both export CSV or JSON.

1. Ingest engine

CSV, Excel, JSON, PDF, text. Drop several at once.
No files yet.

2. API collate engine

One web address per line. Each must return JSON (a list, or an object holding a list). Rows from all addresses are stacked, with a column showing the source.
